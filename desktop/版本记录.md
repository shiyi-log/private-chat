## v0.12.0-private-url-scheme

- 将 Desktop 对外系统 URL scheme 从 `tg://` 改为 `privatechat://`：macOS `Telegram.plist`、Linux `.desktop`、Windows UWP manifest 均不再注册 `tg` 协议。
- 将运行时 URL scheme 注册入口改为 `privatechat`，显示协议名称改为 `Private Chat Link`，`shortAppName` 改为 `privatechat`。
- 在本地 URL 转换流程中新增 `privatechat://` 兼容映射，进入应用后转换为现有内部 `tg://` 本地处理流程，降低大面积替换深链 handler 的回归风险。
- 扩展 `scripts/verify_private_chat_desktop_config.py`，新增 macOS/Linux/UWP/运行时注册和 `privatechat://` 转换检查。
- 已完成 macOS Debug 增量构建：`xcodebuild -project out/Telegram.xcodeproj -scheme Telegram -configuration Debug -parallelizeTargets -hideShellScriptEnvironment build` 返回 `BUILD SUCCEEDED`。
- 已验证生成产物 URL scheme：`out/Debug/Private Chat.app/Contents/Info.plist` 中 `CFBundleURLSchemes = privatechat, tonsite`，并通过 `codesign --verify --deep --strict "out/Debug/Private Chat.app"`。
- 当前内部本地 handler 仍使用 `tg://` 作为实现细节；后续如要完全移除内部命名，需要分阶段重构所有深链生成和解析点。

## v0.11.0-disable-official-update-crash-defaults

- 扩展 `scripts/verify_private_chat_desktop_config.py`，新增自动更新和崩溃上报默认关闭策略检查。
- 当前仍未接入自建更新服务、自建崩溃收集服务或正式支持链接；这些保持为后续服务化任务。
